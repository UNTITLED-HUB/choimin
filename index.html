jCAPTCHA

원본 Roblox Lua jCAPTCHA를 웹(HTML/JS)으로 이식한, 클라이언트 전용 장난 CAPTCHA 모음입니다. 문제를 풀어야 통과되는 V3와, 접속 시간대만으로 자동 통과/차단을 가르는 V2 두 가지 버전이 있고, 한 페이지에 같이 써도 서로 충돌하지 않습니다.

🛡️ jCAPTCHA V3 데모

아래는 문제 풀이형(V3) 데모입니다. 체크박스를 누르면 14개 문제 중 3개가 무작위로 출제되고, 각 문제마다 정해진 "함정 답"만 피하면 통과됩니다.

🕓 jCAPTCHA V2 데모

아래는 접속 시간대 기반(V2) 데모입니다. 별도 조작 없이 자동으로 "검사 중" → 통과/차단 결과가 표시됩니다.

📦 파일 구성

파일 용도
jcaptcha.min.js V3 (문제 풀이형) 배포용 스크립트. 이 페이지의 데모가 사용하는 실제 파일.
jcaptcha-v2.js V2 (접속 시간 자동 검사) 소스. 필요한 페이지에 별도로 추가해서 사용.
index.html 사용 예시 겸 실제 배포 페이지 (지금 보고 있는 이 페이지)
gwitricks.mp3 문제 10번(노래 맞추기)에 쓰이는 음원
mc1.mp3 문제 14번(가사 채우기)에 쓰이는 음원 — 아직 저장소에 없음, 추가되면 같은 폴더에 올려야 함

🚀 사용법 & 코드 로드

HTML에 두 줄만 추가하면 data-jcaptcha-v3 속성이 붙은 요소마다 캡차가 자동으로 렌더링됩니다. (이 저장소는 GitHub Pages로 배포되므로, 같은 저장소 안에서는 절대경로 대신 파일명만 적어도 됩니다.)

<div data-jcaptcha-v3></div>
<script src="jcaptcha.min.js"></script>

다른 사이트에서 불러올 때는 GitHub Pages 주소를 그대로 사용하세요 (아래 "GitHub Pages로 불러오기" 참고).

⚡ 결과 콜백 등록

<script>
  window.jcaptchaV3OnSuccess = function(data) {
    console.log('인증 성공, 토큰:', data.token);
    // 여기서 폼 제출 / 서버 전송 등 처리
  };

  window.jcaptchaV3OnError = function(data) {
    console.log('인증 실패');
  };
</script>
  • jcaptchaV3OnSuccess : 3문제를 함정 없이 통과하면 호출됨
  • jcaptchaV3OnError : 함정 답을 고르거나 2개 이상 건너뛰면 호출됨 (실패 후 자동으로 문제 재시작)

🌐 GitHub Pages로 불러오기 (권장)

이 저장소는 GitHub Pages로 배포되어 있어서, 아래 고정 주소로 안정적으로 불러올 수 있습니다. (이전에 쓰던 jsDelivr /latest/ 경로는 실제로 존재하지 않는 경로라 항상 로드에 실패했습니다 — 이번에 이 주소로 교체했습니다.)

<script src="https://untitled-hub.github.io/choimin/jcaptcha.min.js"></script>

V2를 함께 쓰려면 같은 방식으로 jcaptcha-v2.js를 추가로 불러오면 됩니다.

<div data-jcaptcha-v2></div>
<script src="https://untitled-hub.github.io/choimin/jcaptcha-v2.js"></script>

⚙️ 동작 방식 및 주의사항

  • 동작 방식(V3): 체크박스 클릭 ➔ 14문제 중 3개 무작위 출제 ➔ 함정을 피해서 통과 시 jcaptchaV3OnSuccess 콜백 및 토큰 발급. 2개 이상 건너뛰어도 실패 처리됩니다.
  • 동작 방식(V2): 요소가 페이지에 있으면 자동으로 "검사 중" 연출 후, 접속 시각(브라우저 로컬 시간 기준)만으로 통과/차단을 결정합니다. 실제 봇 탐지 기능은 없습니다.
  • mp3 파일 위치: gwitricks.mp3는 jcaptcha.min.js와 같은 폴더에 있어야 문제 10번에서 음원이 재현됩니다. (문제 14번용 mc1.mp3는 아직 저장소에 없어 해당 문제가 나오면 음원 없이 표시됩니다.)
  • 클라이언트 전용: V2, V3 모두 클라이언트(브라우저) 검증 전용입니다. 로그인·결제처럼 실제로 막아야 하는 상황에는 발급된 token을 서버에서도 검증하는 절차가 반드시 필요합니다.

🌐 Expansion APP

브라우저 장난 확장앱

📋 소개

Choimin.Lnc는 웹 브라우징을 더 재미있게 만드는 강력한 확장앱입니다. Chrome 및 Naver Whale 브라우저에서 작동하며 다양한 재미있는 효과를 제공합니다.

✨ 기능

  • 🌐 사이트 접속 이벤트 - 특정 사이트 방문 시 자동으로 효과 실행
  • ⌨️ 단축키 이벤트 - 키 연속 입력으로 원하는 동작 수행
  • 🎨 전체 탭 설정 - 모든 탭에 공통 효과 적용
  • 🔄 화면 회전 - 0°, 90°, 180°, 270° 회전 가능
  • 🖱️ 커서 변경 - 커서 이미지 변경
  • 🖼️ 이미지 대체 - 페이지 이미지 변경

🚀 설치법

Chrome 설치

1. chrome://extensions 접속
2. 우측 상단 '개발자 모드' 활성화
3. '압축 해제 확장앱 로드' 클릭
4. choimin-lnc 폴더 선택
5. 완료

Naver Whale 설치

1. 메뉴 → '확장앱 관리'
2. '개발자 모드' 활성화
3. '압축 해제 확장앱 로드' 클릭
4. choimin-lnc 폴더 선택
5. 완료
