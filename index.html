jCAPTCHA

원본 Roblox Lua jCAPTCHA를 웹(HTML/JS)으로 그대로 이식한 클라이언트 전용 CAPTCHA입니다.

🛡️ jCAPTCHA 데모

📦 파일 구성

파일 용도
jcaptcha.js 원본 소스 (수정할 땐 이 파일)
jcaptcha.min.js 실제 배포용 (CDN에 올리는 파일)
demo.html 사용 예시
gwitricks.mp3 문제 10번(노래 맞추기)에 쓰이는 음원

🚀 사용법 & 코드 로드

HTML에 두 줄만 추가하면 data-jcaptcha 속성이 붙은 요소마다 캡차가 자동으로 렌더링됩니다.

<div data-jcaptcha></div>
<script src="https://cdn.jsdelivr.net/gh/UNTITLED-HUB/choimin/latest/jcaptcha.min.js"></script>

⚡ 결과 콜백 등록

<script>
  window.jcaptchaOnSuccess = function(data) {
    console.log('인증 성공, 토큰:', data.token);
    // 여기서 폼 제출 / 서버 전송 등 처리
  };

  window.jcaptchaOnError = function(data) {
    console.log('인증 실패');
  };
</script>
  • jcaptchaOnSuccess : 3문제를 함정 없이 통과하면 호출됨
  • jcaptchaOnError : 함정 답을 고르거나 2개 이상 건너뛰면 호출됨 (실패 후 자동으로 문제 재시작)

🌐 GitHub + CDN으로 불러오기

GitHub에 올린 파일은 jsDelivr CDN을 통해 불러올 수 있습니다.

<script src="https://cdn.jsdelivr.net/gh/UNTITLED-HUB/choimin/latest/jcaptcha.min.js"></script>

⚙️ 동작 방식 및 주의사항

  • 동작 방식: 체크박스 클릭 ➔ 12문제 중 3개 무작위 출제 ➔ 함정을 피해서 통과 시 jcaptchaOnSuccess 콜백 및 토큰 발급.
  • mp3 파일 위치: gwitricks.mp3는 jcaptcha.min.js와 같은 폴더에 있어야 문제 10번에서 음원이 재현됩니다.
  • 클라이언트 전용: 본 모듈은 클라이언트 검증 전용이므로 실제 서비스 적용 시 발급된 token을 서버에서도 검증해야 합니다.

🌐 Expansion APP

브라우저 장난 확장앱

📋 소개

Choimin.Lnc는 웹 브라우징을 더 재미있게 만드는 강력한 확장앱입니다. Chrome 및 Naver Whale 브라우저에서 작동하며 다양한 재미있는 효과를 제공합니다.

✨ 기능

  • 🌐 사이트 접속 이벤트 - 특정 사이트 방문 시 자동으로 효과 실행
  • ⌨️ 단축키 이벤트 - 키 연속 입력으로 원하는 동작 수행
  • 🎨 전체 탭 설정 - 모든 탭에 공통 효과 적용
  • 🔄 화면 회전 - 0°, 90°, 180°, 270° 회전 가능
  • 🖱️ 커서 변경 - 커서 이미지 변경
  • 🖼️ 이미지 대체 - 페이지 이미지 변경

🚀 설치법

Chrome 설치

1. chrome://extensions 접속
2. 우측 상단 '개발자 모드' 활성화
3. '압축 해제 확장앱 로드' 클릭
4. choimin-lnc 폴더 선택
5. 완료

Naver Whale 설치

1. 메뉴 → '확장앱 관리'
2. '개발자 모드' 활성화
3. '압축 해제 확장앱 로드' 클릭
4. choimin-lnc 폴더 선택
5. 완료
